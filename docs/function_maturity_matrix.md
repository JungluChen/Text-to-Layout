# Function maturity matrix

**Audited:** 2026-08-04  
**Snapshot:** `454e7c6` (`main`)
**Rule:** maturity describes committed evidence, not intended architecture.

## Classification

| Class | Meaning in this repository |
| --- | --- |
| `PRODUCTION` | Process-qualified, supported, monitored, and backed by real use. No subsystem currently meets this bar. |
| `VALIDATED` | Deterministic behavior has repeated automated tests and bounded, truthful claims. It may still be core-only or analytical. |
| `EXPERIMENTAL` | Real implementation exists but its domain, platform support, or validation is incomplete. |
| `PARTIAL` | A meaningful subset works; required stages are explicitly absent. |
| `PLACEHOLDER` | Interface or handoff exists, but the essential computation does not. |
| `SYNTHETIC_ONLY` | Exercises a workflow with generated fixtures or assumed distributions; it is not empirical validation. |
| `BROKEN` | Intended behavior reproducibly fails or can produce an invalid claim. No known current core path is left in this state. |
| `DEPRECATED` | Retained for compatibility or historical reference; not the supported product path. |

`VALIDATED` never means numerical convergence, physics signoff, measurement
calibration, or fabrication readiness unless the row explicitly says so.

`BROKEN`, WSL is unexecuted, Josephson nonlinear solving is a prepared-only
placeholder, and no current cross-solver or real-measurement validation exists.

with a real open-source solver and repeatable convergence evidence.
