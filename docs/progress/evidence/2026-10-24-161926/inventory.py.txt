from pathlib import Path
from collections import Counter
import hashlib,json
from textlayout.external.qeda_syntax import Atom,Expression,parse_footprint_syntax
base=Path('docs/progress/evidence/2026-10-23-220348')
def name(node):
    return node.children[0].value if isinstance(node,Expression) and node.children and isinstance(node.children[0],Atom) else '<invalid>'
def walk(node,path,rows):
    if isinstance(node,Atom): return
    path=path+'/'+name(node)
    rows.append({'path':path,'atoms':[x.value for x in node.children[1:] if isinstance(x,Atom)],'children':[name(x) for x in node.children[1:] if isinstance(x,Expression)]})
    for x in node.children[1:]: walk(x,path,rows)
results=[]
for p in sorted(base.glob('*.kicad_mod')):
    raw=p.read_bytes(); result={'file':str(p),'sha256':hashlib.sha256(raw).hexdigest()}
    try:
        root=parse_footprint_syntax(raw); rows=[];walk(root,'',rows)
        result.update(syntax='parsed',top_level_counts=dict(Counter(name(x) for x in root.children[2:])),structure=rows)
    except ValueError as e: result.update(syntax='rejected',error=str(e))
    results.append(result)
print(json.dumps({'scope':'Structural inventory only; no semantic acceptance', 'cases':results},indent=2))
