## Scientific finding and correction

With scikit-rf absent, `read_sparameters` used a small Touchstone fallback.
A `.s2p` row with only `frequency, S11, S21` was accepted as a full two-port
result even though S12 and S22 were absent. A `# GHz Z RI R 50` file was
treated as S-parameters, and descending frequencies were accepted. A bare
`#` option line interpreted `5 0.5 90` as 5 Hz and `0.5+90j`; the specified
defaults mean 5 GHz and 0.5 at +90 degrees. Each direct or focused-test
failure reproduced twice unchanged before its correction.

The [IBIS Touchstone 2.1 specification](https://ibis.org/touchstone_ver2.1/touchstone_ver2_1.pdf)
defines complete Version 1.x 1-/2-port rows, increasing frequency, and the
GHz/S/MA/50-ohm option defaults. The fallback now requires exactly three
values per `.s1p` row or nine per `.s2p` row, rejects non-S data and unsupported
Touchstone 2.x keywords without scikit-rf, honors option defaults and inline
comments, and validates nonempty/equal-length finite ordered sweeps plus a
positive finite reference impedance. The scikit-rf path also receives the
common sweep checks. This is file-integrity validation, not proof of solver
convergence or reference accuracy. Other Touchstone versions/port counts
require the optional scikit-rf parser.

Three committed openEMS `.s2p` examples still parsed (401 samples each); two
historically all-NaN examples remained rejected as non-finite. The guidebook's
exact `uv run python -c ...` command returned `401 1500000000.0
12000000000.0 50.0` on the existing CPW example. No new openEMS simulation,
geometry/material comparison, convergence estimate or commercial-solver
comparison was performed. The generated status documents were updated only
